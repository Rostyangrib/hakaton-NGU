# История изменений

Журнал завершённых этапов реализации. Запись добавляется после соответствующего коммита и содержит его идентификатор, изменения и выполненные проверки. Служебные коммиты, обновляющие только этот журнал, отдельно не перечисляются.

## 2026-10-16 — Подготовка проекта

Коммит: `bffeecf` — «Подготовлены материалы кейса и структура проекта».

- Подключён репозиторий `Rostyangrib/hakaton-NGU`, начальная ветка `main`.
- Сохранены исходное условие, русский перевод, архив, распакованные материалы и аналитический ноутбук.
- Добавлены README, правила исключения временных файлов и SDK, журнал изменений.
- Проверки: удалённый репозиторий доступен и изначально пуст; временные каталоги не включены в коммит. Особенности переводов строк исходных тестов сохранены без изменения.

## 2026-10-16 — Адаптивное решение и модульные проверки

Коммит: `9edb37a` — «Реализован адаптивный алгоритм укладки труб на Cangjie».

- Реализованы Best Fit на прогреве, окно 1024 поступлений, сглаживание, дополнительный вес длинных труб и плавное включение статистики с 201-го по 400-е поступление.
- Добавлены два индекса свободных промежутков, объединение соседних участков, использование хвоста перед расширением и ограничение поиска 41 кандидатом.
- Реализован интерактивный протокол с немедленным `flush` и завершением на `0`.
- Подготовлен `build.ps1`; SDK 1.0.5 установлен локально после проверки официального SHA-256. Исполняемые файлы и SDK исключены из Git.
- Учтено исключение Cangjie 1.0.5 при направленном обходе пустого `TreeMap`; стандартные потоки переведены на актуальный `std.env`.
- Проверки: сборка `-O2` без предупреждений; 12 модульных тестов прошли, включая 27 200 случайных команд с независимой метровой моделью и сверкой ускоренного поиска с полным перебором. Первый официальный тест через `runner.py`: балл 0,09, KPI 0,9.

## 2026-10-16 — Выполнение ограничения CPU

Коммит: `0b2d5fe` — «Ускорены индексы промежутков и интерактивный ввод-вывод».

- Первый полный прогон выявил превышения CPU; это не было принято за успешное выполнение ограничений.
- Направленные обходы позиции заменены точными хеш-индексами границ. Короткие длины доступны через массив корзин, начальные позиции — через минимальные кучи с ленивым удалением.
- Ввод и вывод переведены на непосредственное чтение/запись дескрипторов через штатный C FFI Cangjie. Ответ записывается целиком сразу; буферы освобождаются при завершении. Для Windows включён бинарный режим стандартных дескрипторов текущего процесса.
- Формулы статистики, параметры, порядок выбора кандидатов и правила разрешения равенств сохранены.
- Проверки: 13 модульных тестов без ошибок, включая повторное использование одного промежутка; потоковые ответы, CRLF, пробелы, разбиение команды на части и отсутствие ответа на `0`. Отдельный прогон теста 15: KPI 0,947714, CPU 3,969 с, пиковый рабочий набор около 27,6 МиБ. Финальный полный прогон всех сценариев выполняется следующим этапом.
