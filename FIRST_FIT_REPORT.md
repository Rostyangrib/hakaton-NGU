# First Fit: версия для пробной отправки

Дата: 2026-10-17 (Asia/Irkutsk).

Отправляемый файл: `solution_first_fit.cpp`. Компилятор: GCC C++ 14.2, C++20. Файл самостоятельный; дополнительные исходники и материалы тестов не нужны.

При каждом поступлении выбирается подходящий свободный промежуток с наименьшей начальной координатой, труба кладётся с его левого края. При удалении соседние свободные промежутки объединяются. Если места нет, используется хвост и докапывается минимально необходимое количество участков по 20 м. Статистика и переключение стратегий отсутствуют.

Поиск использует 40 корзин длин (последняя включает все промежутки от 40 м): минимум начальных координат подходящих корзин точно совпадает с First Fit. Сложность команды O(40 + log G), память O(G + P), где G — число промежутков, P — число поступивших труб.

## Воспроизведение

```powershell
$env:PATH = (Join-Path $PWD '.tools/w64devkit/bin') + ';' + $env:PATH
& ./.tools/w64devkit/bin/g++.exe -std=c++20 -O2 -Wall -Wextra -Wpedantic -static solution_first_fit.cpp -o build/solution-first-fit.exe
python tools/check_best_fit.py build/solution-first-fit.exe --policy first-fit
python tools/check_open_tests.py --language cpp --solution build/solution-first-fit.exe --source solution_first_fit.cpp --report reports/kpi_first_fit_windows.json
```
